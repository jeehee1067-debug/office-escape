# S1FA 방탈출 : 분석기술팀 탈출 대작전

40명 이상이 동시에 접속해 즐기는 **사내 이벤트용 실시간 방탈출 웹게임**입니다.
GitHub Pages(정적 호스팅) + Firebase Realtime Database 로 동작하며, 서버 코드가 필요 없습니다.

> 디자인은 포켓몬(GBA) 스타일을 참고했습니다. 배경·캐릭터는 이미지 파일이 아니라
> **240×160 / 32×48 해상도로 코드에서 직접 찍은 도트 그래픽**이라 용량이 거의 없고
> 어떤 화면에서도 선명하게 확대됩니다.

---

## 1. 바로 실행하기

### GitHub Pages 로 배포
1. 이 저장소를 GitHub 에 올립니다.
2. `Settings → Pages → Source` 를 `main` (또는 배포용 브랜치) / `/ (root)` 로 지정합니다.
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 로 접속하면 바로 플레이할 수 있습니다.

### 로컬에서 확인
```bash
python3 -m http.server 8000
# http://localhost:8000
```

> Firebase 에 연결하지 못하면 자동으로 **오프라인 모드**로 전환되어 그 브라우저 안에서만
> 진행됩니다(같은 PC의 여러 탭끼리는 동기화). 실제 행사에서는 반드시 Firebase 를 연결하세요.

## 2. Firebase 연결 (40명 동시 접속용)

1. [Firebase 콘솔](https://console.firebase.google.com/) 에서 프로젝트를 만들고
   **Realtime Database** 를 생성합니다.
2. `assets/js/net.js` 상단의 `firebaseConfig` 를 내 프로젝트 값으로 교체합니다.
3. **Realtime Database → 규칙** 탭에 `database.rules.json` 의 `rules` 내용을 붙여넣고 게시합니다.

### 규칙이 지켜주는 것 (기록 위·변조 방지)
| 대상 | 규칙 |
|---|---|
| 문제 정답 기록 `runs/*/rooms/*/solves/*` | **한 번 쓰면 수정·삭제 불가** (`!data.exists()`), 점수 상한 12,000점, 기록 시각은 서버 시각만 허용 |
| 방 종료 기록 `runs/*/rooms/*/done` | **한 번만 기록 가능**, 소요시간·보너스 상한 검증 |
| 오답 횟수 `wrong` | 증가만 가능(줄일 수 없음) |
| 게임 진행 제어 `global`, 데이터 삭제 | **관리자 키를 아는 사람만** 쓰기 가능 |
| 관리자 키 `config` | 클라이언트가 **읽을 수 없음** (`.read: false`) |

즉 참가자가 개발자도구로 `localStorage` 를 고쳐도 점수·시간은 바뀌지 않습니다.
화면 표시값은 매번 **서버 기록으로부터 다시 계산**됩니다.

## 3. 게임 구성

| 구간 | 내용 |
|---|---|
| 대기실 | 캐릭터 선택 → 근무지(SR3/S1L) → 이름 입력 → 입장. 접속한 사람들이 도트 캐릭터로 함께 서 있음 |
| 1관 | EFA1 파트 — 서류박스 치우기 / 모니터 순서대로 켜기 / 파트장님과 대화 |
| 2관 | EFA2 파트 — 케이블 색 맞춰 잇기 / 서랍 3칸 중 진짜 찾기 / 컵 집어 커피 내리기 |
| 3관 | PFA·VSEM — 모니터 얼룩 문질러 닦기 / VSEM 배율 맞추기 / 시편 트레이에 옮기기 |
| 4관 | 캔틴룸 — 컵 더미 치워 금고 번호 찾기 → 금고 키패드 열기 / 자판기 버튼 순서 |
| 중간 대기실 | 방을 마칠 때마다 이 방 점수·누적 점수·실시간 순위 확인 |
| 결과 발표 | 시상대 + 방별 기록 + 전체 순위, CSV 내보내기 |

- 방마다 **5분**, 총 **4개 방 = 20분**.
- 각 방에는 **문제 5개**가 준비돼 있고 그중 **3개**가 출제됩니다.
  팀이 구성되어 있으면 **팀마다 다른 조합**이 나와 컨닝이 어렵습니다.
- **낚시 요소**: 가방·텀블러·도시락·먼지떨이 등은 아무 단서도 없습니다.
  일부는 걸리면 감점(기본 500점)됩니다.
- 오답은 1,500점 감점, 빨리 탈출할수록 최대 3,000점 시간 보너스.

## 4. 관리자 사용법

로그인 화면의 **👑 관리자 로그인** → 비밀번호 입력.
기본 비밀번호는 **`00`** 이며 `assets/js/data.js` 의 `CONFIG.ADMIN_PASSWORD` 에서 변경합니다.

> 비밀번호를 바꾼 뒤에는 Firebase 의 `v2/config/adminKey` 값을 한 번 지워야
> 새 비밀번호가 등록됩니다(최초 1회만 기록되는 값입니다).

관리자 패널(👑 버튼)에서 할 수 있는 것:

- 🚀 **게임 시작** — 전원을 1관으로 보내고 타이머 시작
- ➡ **다음 방 열기** / ⬅ **이전 방** — 진행 통제
- ⏸ **일시정지 / 재개** — 멈춘 시간은 제한시간에서 제외됩니다
- 🏠 **전원 대기실로**
- 🧹 **현재 방 리셋** — 그 방의 모든 참가자 진행 기록만 삭제하고 타이머 재시작
- 🎲 **랜덤 팀 구성** — SR3/S1L 이 고루 섞이도록 자동 배분, CSV 저장
- 🏁 **결과 발표**
- 🔄 **전체 데이터 초기화** — 참가자·기록·팀 전부 삭제하고 참가자를 로그인 화면으로 보냄
  (**관리자는 로그아웃되지 않습니다.** 관리자 로그아웃은 패널 맨 아래 버튼으로만)
- 👥 **참가자 실시간 현황** — 접속 여부 / 근무지 / 이름 / 현재 방 / 푼 단서 / 점수 / 시간

관리자가 F5 를 눌러도 권한과 화면 위치가 그대로 유지됩니다.

## 5. 참가자 이어하기

- 접속하면 기기마다 고유 ID 가 발급되어 `localStorage` 에 저장됩니다.
- 브라우저를 껐다 켜거나 새로고침해도 **서버에 저장된 진행 상황을 그대로 이어서** 진행합니다.
- 타이머는 각자의 시계가 아니라 **서버 시각** 기준이라 모든 참가자가 같은 시간에 시작·종료됩니다.

## 6. 내용 수정하기

거의 모든 내용은 **`assets/js/data.js`** 한 파일에 모여 있습니다.

| 항목 | 위치 |
|---|---|
| 관리자 비밀번호, 제한시간, 감점/보너스 | `CONFIG` |
| 플레이어 캐릭터 8종 | `AVATARS` |
| 각 방 파트장님 | `BOSSES` |
| **문제은행 (방마다 5문제)** | `BANK` |
| 방 배치 · 기믹 · 낚시 소품 | `ROOMS` |

문제 형식:
```js
{ id: 'r1q1', type: 'choice', score: 6000,
  q: '질문', choices: ['1번','2번','3번','4번'], ans: 1,   // ans = 0부터 시작
  ok: '정답 시 파트장님 대사' }

{ id: 'r1q5', type: 'short', score: 7000,
  q: '질문', hint: '힌트', ans: ['정답', '허용답안2'],       // 띄어쓰기·대소문자 무시
  ok: '정답 시 대사' }
```

### 캐릭터 도트를 직접 고치고 싶다면
`assets/js/sprites.js` 는 **문자 하나 = 픽셀 하나**인 32×48 그리드입니다.
`S`(피부) `h`(머리) `c`(상의) 처럼 문자만 바꾸면 모양이 바뀝니다. 색은
`assets/js/pixel.js` 의 `paletteFor()` 에서 캐릭터별 색상값으로 자동 계산됩니다.

직접 그린 **PNG 스프라이트로 교체**할 수도 있습니다:
```js
PX.setCharImage('jihun', 'assets/img/char/jihun.png');   // 32x48 비율 권장
// data.js 의 AVATARS 항목에 sprite: 'jihun' 추가
```

## 7. 파일 구조

```
index.html                 화면 뼈대
database.rules.json        Firebase 보안 규칙 (기록 위·변조 방지)
assets/css/style.css       GBA/포켓몬 스타일 UI
assets/js/
  sprites.js               32x48 캐릭터 도트 데이터
  pixel.js                 도트 렌더링 엔진 (캐릭터·소품·배경 씬)
  data.js                  ★ 설정 / 문제은행 / 방 구성
  fallback-db.js           Firebase 미연결 시 오프라인 대체 저장소
  net.js                   Firebase 동기화 · 서버시각 · 기록 저장
  ui.js                    대사창 / 모달 / 토스트 / 칩튠 효과음
  puzzles.js               미니게임(케이블·얼룩닦기·배율·키패드) + 드래그
  game.js                  게임 본체 (씬 구성 · 기믹 · 타이머 · 채점)
  admin.js                 관리자 통제 패널
  boot.js                  로그인 · 세션 복구 · HUD
assets/img/                배경 사진(참고용) 및 BGM
```
